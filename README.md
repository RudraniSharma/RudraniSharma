## 📌 Featured project

### [Explainable Credit Risk](https://github.com/RudraniSharma/explainable-credit-risk)
A 2026 re-implementation of my IEEE-published research on explaining neural networks for credit risk, using ≈890k real Lending Club loans.
- Compares an MLP against logistic regression and gradient boosting (ROC-AUC ≈ 0.70–0.71 on leakage-free data)
- Explains the model with **Garson's algorithm, permutation importance, SHAP, LIME and surrogate rules**, and measures how far these methods agree
- Documents a **target-leakage fix** in the original 2020 analysis, with a reproducible pipeline and unit tests
